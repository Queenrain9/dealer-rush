# DEALER RUSH 1.0

Native portrait iPhone training game. Three modes generate situations locally. Pure logic derives every correct answer. Each submitted answer is stored with SwiftData, allowing stats and a daily run to resume after termination. Game Center is an optional adapter; local play never waits for authentication.

Flow: `QuestionFactory → HandEvaluator/PotCalculator → TrainingSession → AnswerRecord → TrainingStats/ScoreCalculator → SwiftUI`. A local calendar date and stable FNV seed define ten daily questions, with answer records keyed by date and index. The daily sequence rotates Showdown, Pot Calculation and Side Pot. A session has ten questions. Its score and combo are computed on every answer; a daily run restores its saved index, score and combo. Each record stores the rating before and after the answer. Rating starts at 1000 and reflects cumulative correctness, response time, combo and difficulty through earned points. Tier thresholds, mode mastery and recent progress comparison live in the logic layer. Leaderboards publish the current rating and daily total; weekly and all-time rating are distinct Game Center identifiers. The Game Center reader is optional and shows only returned entries.

Limitations: the local daily challenge is tied to the device calendar and can be changed by adjusting the system date. Players on different devices share the date seed and generation algorithm in this build, but future releases must preserve that algorithm or provide server-issued question IDs to keep old daily sets stable. Game Center needs bundle ID, entitlement, signing, leaderboard configuration and device testing by the Apple Developer account holder. Xcode and iPhone runtime verification require macOS.
